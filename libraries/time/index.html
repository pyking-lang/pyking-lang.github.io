time

Dates and times: reading the clock, and rendering an instant.

An instant is a whole number of seconds since 1970-01-01 00:00:00, and every date and time is in UTC on every host.

compact_format

compact_format: String = "yyyyMMddHHmmss"

The format string for a date and a time with nothing between the fields, as in 20261004123000, which sorts in time order as text.

format

def format(t: (Int, Int, Int, Int, Int, Int), fmt: String) -> String

Writes a date and time as text, following the pattern fmt. In fmt, yyyy is the year, MM the month, dd the day, HH the hour, mm the minute and ss the second, each padded with zeros. The characters - : / . ,, a space, T and Z are copied as they are. Any other character ends the text there.

Parameters

  • t: (year, month, day, hour, minute, second), as now and of_instant answer.
  • fmt: the pattern; iso8601_format, date_format, time_format, datetime_format and compact_format are ready-made ones.

Returns

The formatted text.

local_now

def local_now() -> (Int, Int, Int, Int, Int, Int)

Reads the clock once and splits it into a date and a time of day, as a clock on the wall shows it where the program runs: in the time zone of the computer, or on a web page the reader’s.

Returns

(year, month, day, hour, minute, second), with the month 1 to 12 and the day 1 to 31.
