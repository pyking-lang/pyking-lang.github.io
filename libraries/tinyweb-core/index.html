Page

web_init

def web_init(port: Int = 0) -> ()

Starts the program’s page. Run as pyk program.pyk or compiled, it serves the page on port and prints its address; in a browser it does nothing, since the page is there already.

Parameters

  • port: the port to serve the page on; 0, the default, takes any free one.

Example

import tinyweb as tw
tw.web_init(0)
tw.label("Hello")

Point

struct Point(x: Int, y: Int)

A point on a canvas, in whole pixels from its top left corner: what polygon and path take a list of.

Parameters

  • x: how far right.
  • y: how far down.

Example

Style

struct Style(fill: color.Color = color.black, stroke: color.Color = color.none, width = 1, alpha = 1.0, paint: color.Paint = color.Plain(color.none))

How a shape is drawn, defined once and given to as many shapes as look alike with style = .... A shape’s own argument left at its default takes the style’s value, and one written wins.

Parameters

  • fill: the colour inside; black by default.
  • stroke: the colour of the outline, or of a line; color.none (no outline) by default.
  • width: how thick the outline or line is, in pixels; 1 by default.
  • alpha: how opaque, from 0.0 to 1.0; 1.0 by default.
  • paint: a gradient to fill with instead of fill.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 80)
glow = tw.Style(fill = color.yellow, stroke = color.orange, width = 3)
tw.circle(c, 40, 40, 30, style = glow)
tw.circle(c, 120, 40, 30, color.red, style = glow)
tw.circle(c, 170, 40, 20, style = tw.Style(alpha = 0.5, ..glow))

Pointer

struct Pointer(x: Int, y: Int, down: Bool)

Where the pointer is on a canvas, and whether its button is held: what mouse answers.

Parameters

  • x: how far right, in the canvas’s pixels.
  • y: how far down.
  • down: whether the button is held.

Example

Canvas

canvas

def canvas(width: Int, height: Int) -> String

Adds a canvas to draw on, below everything already on the page. It starts white.

Parameters

  • width: its width in pixels.
  • height: its height in pixels.

Returns

The canvas’s identifier, which the drawing functions take as c: "canvas", with a number added where something on the page has that name already.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 60)
tw.rect(c, 10, 10, 180, 40, color.teal)

clear

def clear(c: String, fill: color.Color = color.white) -> ()

Fills the whole canvas c with one colour, wiping out what was drawn, and starts it afresh: no transformation, shadow or blending is kept.

Parameters

  • c: the canvas, as canvas answered.
  • fill: the colour; white by default.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 60)
tw.clear(c, color.navy)

Lines and clipping

line_style

def line_style(
    c: String,
    cap: String = "round",
    join: String = "round",
    dash: Float = 0.0,
    gap: Float = 0.0,
    offset: Float = 0.0,
    dash2: Float = 0.0,
    gap2: Float = 0.0,
) -> ()

Sets how lines drawn on the canvas c after it end and turn their corners, and whether they are dashed.

Parameters

  • c: the canvas.
  • cap: how a line ends: "round" (the default), "butt" or "square".
  • join: how a corner turns: "round" (the default), "miter" or "bevel".
  • dash: how long a dash is; 0.0, a solid line, by default.
  • gap: how long the gap after it is; the dash’s length unless given.
  • offset: how far into the pattern the line starts.
  • dash2, gap2: a second dash and gap, for a dash-dot pattern.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(200, 60)
tw.line_style(c, cap = "butt", dash = 10.0, gap = 5.0)
tw.line(c, 10, 30, 190, 30, width = 4)

Text

text

def text(
    c: String,
    x: Int,
    y: Int,
    words: String,
    fill: color.Color = color.black,
    size: Int = 16,
    font: String = "",
    align: String = "left",
    bold: Bool = false,
    alpha: Float = 1.0,
    baseline: String = "top",
    stroke: color.Color = color.none,
    width: Int = 1,
    paint: color.Paint = color.Plain(color.none),
    style: Style = Style(),
) -> ()

Writes text on the canvas c.

Parameters

  • c: the canvas.
  • x, y: where the text goes: its top left corner, unless align and baseline say otherwise.
  • words: what is written.
  • fill: its colour; black by default.
  • size: its size in pixels; 16 by default.
  • font: the font’s name, such as "serif"; the page’s own by default.
  • align: which part of the text is at x: "left", "center" or "right".
  • bold: whether it is bold.
  • alpha: how opaque, from 0.0 to 1.0.
  • baseline: which part is at y: "top", "middle", "alphabetic" or "bottom".
  • stroke: the colour of an outline round each letter; none by default.
  • width: the outline’s width.
  • paint: a gradient to fill the letters with instead of fill.
  • style: a Style for what is not given here.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 60)
tw.text(c, 100, 30, "Hello!", color.navy, size = 24, align = "center", baseline = "middle")

measure_text

def measure_text(
    words: String,
    answer: (Float) -> (),
    size: Int = 16,
    font: String = "",
    bold: Bool = false,
) -> ()

Asks the page how wide a text is, written in a given font, so that something can be placed beside it. The page answers by calling answer with the width in pixels, a moment later.

Parameters

  • words: the text.
  • answer: what is called with its width.
  • size: its size in pixels; 16 by default.
  • font: the font’s name; the page’s own by default.
  • bold: whether it is bold.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(300, 60)
def underline(w: Float):
    tw.line(c, 10, 40, 10 + int(w), 40)
tw.text(c, 10, 10, "Underlined", size = 20)
tw.measure_text("Underlined", underline, size = 20)

Images

load_image

def load_image(name: String) -> String

Starts loading a picture, so that image can draw it. The file is looked for beside the page first, then among the pictures tinyweb ships: ball.png, star.png and tile.png. Drawing a picture before it has loaded waits for it: the page holds that and everything after it until the picture has loaded, so what is drawn later still lands on top of it.

Parameters

  • name: the file’s name, such as "ball.png".

Returns

The picture’s identifier, which image takes: the file’s name, with a number added where something on the page has that name already.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(200, 100)
ball = tw.load_image("ball.png")
tw.image(c, ball, 80, 30, 40, 40)

image

def image(
    c: String,
    picture: String,
    x: Int,
    y: Int,
    w: Int,
    h: Int,
    alpha: Float = 1.0,
) -> ()

Draws a picture load_image loaded on the canvas c, stretched to the rectangle given. A picture not loaded yet is drawn once it has loaded, and what the program draws after it waits until then.

Parameters

  • c: the canvas.
  • picture: the picture, as load_image answered.

Example

sdelay

def sdelay(time: Float) -> ()

Waits, keeping in time with the sound: the program goes on time seconds after the last sdelay ended, on the page’s audio clock. The first waits time seconds from now. Since each counts from where the last one ended rather than from when it was called, a loop of them does not drift, however long what runs between them takes. A program that has fallen behind — where that end has passed already — goes on at once, and the next counts from then.

A sound started after sdelay, with no at of its own, starts exactly where it ends, and what is drawn after it is shown then. While the program waits, the page’s events still arrive: a button’s function runs, and so does on_frame’s. Since the program really waits, print after it comes out then too.

With no page open yet, the program waits for one. It cannot be used in a program compiled for the web target, which cannot wait: run it with the interpreter (pyk, -t iweb, the playground) or compile it for another target.

Parameters

  • time: how long after the last sdelay to go on, in seconds; a negative one is 0.

def play(
    sample: String,

Splash screen

splash

def splash() -> ()

Shows the splash screen: the page is dimmed and a message asks the reader to click, since a browser plays no sound before the reader has clicked or pressed a key. The page waits there — what the program draws next, its frames and its clock — until the reader does. It is shown at most once, and not at all where the reader has already clicked, as in the playground and a notebook. A program that plays a sound calls it at the end of its top level without writing it, and the first play before a click shows it too.
