math

Numbers: trigonometry, powers and logarithms, rounding to an Int, and helpers for drawing and games.

Angles are in radians: sin(pi / 2.0) is 1.0. to_radians and to_degrees convert from and to degrees. abs, min, max, clamp, sign and mod take two Ints or two Floats and answer the same type; everything else takes and answers Floats, so an Int is passed as float(n).

e

e: Float = 2.718281828459045

Euler’s number, the base of the natural logarithm.

Example

inf

inf: Float = 1.0e999

Positive infinity, larger than every other Float. -math.inf is negative infinity.

Example

nan

nan: Float = 0.0 / 0.0

Not a number: what an operation with no answer gives, such as 0.0 / 0.0. A NaN is equal to nothing, itself included, so test for one with is_nan.

Example

atan2

def atan2(y: Float, x: Float) -> Float

The direction in radians from the origin to the point (x, y): the angle a line from (0, 0) to that point makes with the x axis. Unlike atan(y / x), it tells all four quarters of the plane apart. Note the order: y comes first.

Parameters

  • y: the point’s y coordinate.
  • x: the point’s x coordinate.

Returns

The angle, from -π to π.

lerp

def lerp(a: Float, b: Float, t: Float) -> Float

The number a fraction t of the way from a to b: a when t is 0, b when it is 1, and halfway between them when it is 0.5. A t outside 0 to 1 goes past the ends.

Parameters

  • a: where it starts.
  • b: where it ends.
  • t: how far along, usually from 0 to 1.

Returns

a + (b - a) * t.

map_range

def map_range(
    x: Float,
    from_low: Float,
    from_high: Float,
    to_low: Float,
    to_high: Float,
) -> Float

A number moved from one range to another, keeping its place: x is as far from from_low towards from_high as the answer is from to_low towards to_high. A mouse position becomes a volume, a time becomes a color.

Parameters

  • x: the number.
  • from_low: the start of the range x is in.
  • from_high: the end of that range, not equal to from_low.
  • to_low: the start of the range to move it to.
  • to_high: the end of that range.

Returns

The number in the new range. A number outside the first range lands outside the second; clamp keeps it in.
