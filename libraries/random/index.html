random

Random numbers: a Float between 0.0 and 1.0, a whole number in a range, a pick from a list and a list shuffled.

The numbers come from a generator written in Pyking, so a program that calls seed first gets the same numbers on every target — art that comes out the same each time, and a game that can be replayed. Without seed the generator starts from the clock.

choice

def choice(items: [a]) -> a

One of the items, chosen at random. The list must not be empty.

Parameters

  • items: what to choose from.

Returns

The item chosen.

randint

def randint(low: Int, high: Int) -> Int

A random whole number from low to high, both included.

Parameters

  • low: the smallest it may be.
  • high: the largest it may be; where it is below low, the answer is low.

Returns

The number.

seed

def seed(n: Int) -> ()

Starts the generator again from n, so that what follows is the same each time the program runs, on every target.

Parameters

  • n: any whole number; two different ones start two different sequences.

Example

shuffle

def shuffle(items: [a]) -> [a]

The items in a random order: every order equally likely. The list given is left as it was.

Parameters

  • items: what to shuffle.

Returns

A new list holding the same items.
