text

Looking inside a String: its length, its characters, finding and replacing a part, and taking it apart into pieces and words.

A position or a length counts characters — Unicode code points — so "åäö" has length 3 and "👑" length 1 on every target. The first character is at position 0, and a character is a Char, as s[k] gives it. upper, lower, trim and words know the ASCII letters and the ASCII spaces only, so every target answers alike. A String is read as a number by the builtins int and float, and a number written as one by string.

char_at

def char_at(s: String, k: Int) -> Char

The character at position k: s[k], where s has a position k.

Parameters

  • s: the string.
  • k: the position, 0 for the first character.

Returns

That character, or '\0' where s has no position k.

find

def find(s: String, part: String, start: Int = 0) -> Int

Where part first appears in s, at or after position start.

Parameters

  • s: the string to look in.
  • part: what to look for.
  • start: where to begin looking; 0, the start, by default. Below 0 counts as 0.

Returns

The position part begins at, or -1 if it is nowhere from start on. An empty part is found at once, at start.

Returns

That character, or '\0' where n is not one: a negative number, a surrogate (55296 to 57343) or past 1114111.

split

def split(s: String, by: String) -> [String]

The pieces of s between the occurrences of by, from left to right.

Parameters

  • s: the string.
  • by: what separates the pieces. Where it is "", the one piece is s.

Returns

The pieces, one more than there are occurrences of by; a piece is "" where two of them are next to each other or one is at an end.
