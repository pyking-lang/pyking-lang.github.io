tinyweb

Graphics, widgets and sound on a web page, kept in time with each other.

A program builds its page by calling the functions below: each canvas, button, label and slider goes below the ones before it. A canvas is drawn on with clear, circle, rect, line and text, in pixels from its top left corner, and a color is a CSS color such as “#ff0000” or “red”.

A page has a look of its own, the same wherever it is shown: theme picks one of tinyweb’s, the _style functions change every element of one kind, and set_style and set_colors change one element.

A program that handed the page a function — on_click, on_frame and the rest — keeps running after its last line: the page calls the function each time the event happens. Sound and pictures are kept in step by one clock, time: a frame is drawn for a time, and play can start a sound at one.

tinyweb needs a page to show. A program starts with web_init(port), which serves one and prints its address wherever the program runs — pyk program.pyk, the REPL, or any compiled target — and does nothing in a browser, where the page is there already: on a web page, and beside the program in the notebook and the playground.

button

def button(title: String, on_click: () -> () = nothing) -> Int

Adds a button below everything already on the page.

Parameters

  • title: the text on the button.
  • on_click: the function to call each time it is pressed; by default nothing happens.

Returns

The button’s number.

Example

import tinyweb as tw
tw.web_init(0)
var count = 0
def pressed():
    count := count + 1
    print("pressed", count, "times")
tw.button("Count", on_click = pressed)

button_style

def button_style(
    background: String = "",
    color: String = "",
    border: String = "",
    radius: Int = -1,
    font: String = "",
    size: Int = -1,
    padding: Int = -1,
) -> ()

Changes every button on the page, those made already and those made later. Only what is named changes; the rest stays as the theme has it.

Parameters

  • background: a CSS color for the button.
  • color: a CSS color for its text.
  • border: a CSS border, such as "2px solid navy" or "none".
  • radius: how round its corners are, in pixels.
  • font: a font, such as "serif" or "monospace".
  • size: the size of its text, in pixels.
  • padding: the space between its text and its edge, in pixels.

Example

import tinyweb as tw
tw.web_init(0)
tw.button_style(background = "#2f6fdd", color = "white", border = "none", radius = 14, padding = 10)
tw.button("Start")
tw.button("Stop")

canvas

def canvas(width: Int, height: Int) -> Int

Adds a canvas to draw on, below everything already on the page. It starts white.

Parameters

  • width: its width in pixels.
  • height: its height in pixels.

Returns

The canvas’s number, which the drawing functions take as c.

Example

tw.rect(c, 10, 10, 180, 40, "teal")

Changes the frame of every canvas on the page, those made already and those made later. What is drawn on a canvas is not changed.

load_sample

def load_sample(name: String) -> Int

Starts loading a sound file, so that play can play it without a delay. The file is looked for beside the page first, then among the samples tinyweb ships: kick1.wav, snare1.wav, hihat1.wav and piano_c1.wav.

Parameters

  • name: the file’s name, such as "kick1.wav".

Returns

The sample’s number, which play takes.

Example

import tinyweb as tw
tw.web_init(0)
kick = tw.load_sample("kick1.wav")
def hit():
    tw.play(kick)
tw.button("Kick", on_click = hit)

on_frame

def on_frame(draw: (Float) -> ()) -> ()

Calls draw before each frame the page shows, about 60 times a second, with the time the frame is for. This is how a program animates.

Parameters

  • draw: the function to call; it is given the frame’s time in seconds, as time reads it.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(200, 60)
def draw(t: Float):
    tw.clear(c)
    x = int(t * 50.0) - int(t * 50.0) / 200 * 200
    tw.circle(c, x, 30, 10, "orange")
tw.on_frame(draw)

on_key

def on_key(pressed: (String) -> ()) -> ()

Calls pressed each time a key is pressed while the page has the focus.

Parameters

  • pressed: the function to call; it is given the key: a letter or digit as itself, and otherwise the browser’s name for it, such as "ArrowLeft", "Enter" or " ".

Example

import tinyweb as tw
tw.web_init(0)
shown = tw.label("press a key")
def pressed(key: String):
    tw.set_label(shown, "you pressed " ++ key)
tw.on_key(pressed)

on_mouse

def on_mouse(c: Int, click: (Int, Int) -> ()) -> ()

Calls click each time the canvas c is clicked, with where the click was.

Parameters

page_style

def page_style(
    background: String = "",
    color: String = "",
    font: String = "",
    size: Int = -1,
    padding: Int = -1,
    gap: Int = -1,
) -> ()

Changes the page itself: its background, and the text and spacing everything on it shares. Only what is named changes; the rest stays as the theme has it.

Parameters

  • background: a CSS color for the page.
  • color: a CSS color for its text.
  • font: a font, such as "serif", "monospace" or "Georgia".
  • size: the size of its text, in pixels.
  • padding: the space around everything on it, in pixels.
  • gap: the space between one element and the next, in pixels.

Example

import tinyweb as tw

tw.page_style(background = "#fdf6e3", color = "#586e75", font = "serif", size = 18, gap = 16)
tw.label("Solarized, with room to breathe")
tw.button("OK")

play

def play(
    sample: Int,
    at: Float = 0.0,
    volume: Float = 1.0,
    rate: Float = 1.0,
) -> ()

Plays a sample that load_sample loaded.

Parameters

  • sample: the sample’s number, as load_sample answered.
  • at: when to start, in seconds on the page’s clock (see time), which counts from when the page started rather than from now: two seconds from now is at = tw.time() + 2.0, while at = 2.0 is already past once the page has been open two seconds. A time already past, such as the default 0.0, means now.
  • volume: how loud, as a multiple of the sample’s own volume; 1.0 by default.
  • rate: how fast, as a multiple of normal speed; 2.0 plays it twice as fast and an octave higher. 1.0 by default.

Example

import tinyweb as tw
tw.web_init(0)
piano = tw.load_sample("piano_c1.wav")
def chord():
    start = tw.time()
    tw.play(piano, at = start)
    tw.play(piano, at = start + 0.25, rate = 1.25)
    tw.play(piano, at = start + 0.5, volume = 0.7, rate = 1.5)
tw.button("Play", on_click = chord)

theme

def theme(name: String) -> ()

Gives the whole page one of tinyweb’s looks: its colors, fonts, and how buttons, sliders and canvases are drawn. A page starts in "light", which looks the same wherever it is shown. Call it before any of the _style functions, since it forgets what they changed.

The themes are "light", "dark", "plain" (the browser’s own buttons and sliders, on white), "paper" (ink on warm paper, with a serif font) and "retro" (green on black, in a typewriter font). A name that is none of these changes nothing, and says so with debug.

Parameters

  • name: the theme.

Example

import tinyweb as tw
tw.web_init(0)
tw.theme("dark")
tw.label("A dark page")
tw.button("Press me")
tw.slider(0, 10, 3)
c = tw.canvas(160, 40)
tw.circle(c, 20, 20, 12, "orange")

web_init

def web_init(port: Int) -> ()

Starts the program’s page. Run as pyk program.pyk or compiled, it serves the page on port and prints the address to open; in a browser, the notebook or the playground the page is already there and it does nothing. Call it before any other tinyweb function.

Parameters

  • port: the port to serve on; 0 picks any free one.

Example

import tinyweb as tw
tw.web_init(0)
tw.label("The page is ready.")
