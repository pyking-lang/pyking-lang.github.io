tinyweb.smooth

The shapes, with positions, sizes and widths that may fall between pixels: something moving slowly, a thin line at an angle or a picture built from thousands of short strokes looks smoother. Each draws exactly what tinyweb’s function of the same name does.

import tinyweb as tw
import tinyweb.smooth as smooth
tw.web_init(0)
c = tw.canvas(200, 100)
smooth.circle(c, 100.5, 50.25, 20.75)

smooth.Point

struct smooth.Point(x: Float, y: Float)

A point on a canvas whose position may fall between pixels.

Parameters

  • x: how far right.
  • y: how far down.

smooth.circle

def smooth.circle(
    c: String,
    x: Float,
    y: Float,
    radius: Float,
    fill: color.Color = color.black,
    stroke: color.Color = color.none,
    width: Float = 1.0,
    alpha: Float = 1.0,
    paint: color.Paint = color.Plain(color.none),
    style: Style = Style(),
) -> ()

tw.circle, with a position and radius that need not be whole.

Parameters

  • c: the canvas.
  • x, y: its centre.
  • radius: its radius.
  • fill: the colour inside; black by default.
  • stroke: the outline’s colour; none by default.
  • width: the outline’s width.
  • alpha: how opaque, from 0.0 to 1.0.
  • paint: a gradient to fill with instead of fill.
  • style: a tw.Style for what is not given here.

Example

import tinyweb as tw
import tinyweb.smooth as smooth
tw.web_init(0)
c = tw.canvas(200, 100)
smooth.circle(c, 100.5, 50.5, 10.25)

smooth.circles

def smooth.circles(
    c: String,
    circles: [(Float, Float, Float)],
    fill: color.Color = color.black,
    stroke: color.Color = color.none,
    width: Float = 1.0,
    alpha: Float = 1.0,
    style: Style = Style(),

Many circles of one look in one go, each (x, y, radius): quicker than calling circle for each.

Parameters

  • c: the canvas.
  • circles: each circle’s centre and radius.
  • fill: the colour inside; black by default.
  • stroke: the outline’s colour; none by default.
  • width: the outline’s width.
  • alpha: how opaque, from 0.0 to 1.0.
  • style: a tw.Style for what is not given here.

Example

import tinyweb.smooth as smooth
tw.web_init(0)
c = tw.canvas(200, 100)
smooth.circles(c, [(float(x), 50.0, 4.5) for x in range(10, 200, 20)])

smooth.text

def smooth.text(
    c: String,
    x: Float,
    y: Float,
    words: String,
    fill: color.Color = color.black,
    size: Int = 16,
    font: String = "",
    align: String = "left",
    bold: Bool = false,
    alpha: Float = 1.0,
    baseline: String = "top",
    stroke: color.Color = color.none,
    width: Float = 1.0,
    paint: color.Paint = color.Plain(color.none),
    style: Style = Style(),
) -> ()

tw.text, at a position that need not be whole.

Parameters

  • c: the canvas.
  • x, y: where the text goes.
  • words: what is written.
  • fill: its colour; black by default.
  • size: its size in pixels; 16 by default.
  • font: the font’s name; the page’s own by default.
  • align: which part of the text is at x: "left", "center" or "right".
  • bold: whether it is bold.
  • alpha: how opaque, from 0.0 to 1.0.
  • baseline: which part is at y: "top", "middle", "alphabetic" or "bottom".
  • stroke: the colour of an outline round each letter; none by default.
  • width: the outline’s width.
  • paint: a gradient to fill the letters with instead of fill.
  • style: a tw.Style for what is not given here.

Example

import tinyweb as tw
import tinyweb.smooth as smooth
tw.web_init(0)
c = tw.canvas(200, 60)
smooth.text(c, 10.5, 20.25, "Smooth")
