tinyweb

Graphics, widgets and sound on a web page, kept in time with each other.

A program builds its page by calling the functions below: each canvas, button, label and slider goes below the ones before it. A canvas is drawn on with clear, circle, rect, line and text, in pixels from its top left corner, and a color is a CSS color such as “#ff0000” or “red”.

Shapes also come as ellipse, arc, polygon, path and curve, each with an outline and transparency; translate, rotate, scale, push and pop move what is drawn after them, image draws a picture, and shadow and blend give it a glow. Colors can be built with the submodule tinyweb.colors (import tinyweb.colors as colors, then colors.rgb(255, 136, 0)). Checkboxes, radio buttons, a dropdown and fields to type into sit beside the buttons and sliders.

A page has a look of its own, the same wherever it is shown: theme picks one of tinyweb’s, the _style functions change every element of one kind, and set_style and set_colors change one element.

A program that handed the page a function — on_click, on_frame and the rest — keeps running after its last line: the page calls the function each time the event happens. Sound and pictures are kept in step by one clock, time: a frame is drawn for a time, and play can start a sound at one.

tinyweb needs a page to show. A program starts with web_init(port), which serves one and prints its address wherever the program runs — pyk program.pyk, the REPL, or any compiled target — and does nothing in a browser, where the page is there already: on a web page, and beside the program in the notebook and the playground.

arc

def arc(
    c: String,
    x: Int,
    y: Int,
    radius: Int,
    start: Float,
    end: Float,
    color: String = "#000000",
    outline: String = "",
    outline_width: Int = 1,
    alpha: Float = 1.0,
) -> ()

Draws a slice of a circle on the canvas c, from the angle start to the angle end, in degrees: 0 points right, and angles turn clockwise, as the canvas’s y grows downwards.

Parameters

  • c: the canvas, as canvas answered.
  • x, y: the centre of the circle, in pixels.
  • radius: its radius in pixels.
  • start, end: where the slice starts and ends, in degrees.
  • color: a CSS color to fill it with; black by default, and "" for none, which leaves only the curved edge to outline.
  • outline: a CSS color to outline it with; "", none, by default.
  • outline_width: how thick the outline is, in pixels; 1 by default.
  • alpha: how opaque it is, from 0.0 to 1.0; 1.0 by default.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(200, 100)
tw.arc(c, 60, 50, 40, 30.0, 330.0, "gold")
tw.arc(c, 150, 50, 40, 180.0, 360.0, "", outline = "red", outline_width = 4)

Draws a curve from (x1, y1) to (x2, y2) pulled towards two control points, the first near the start and the second near the end: a cubic Bézier curve, which can bend two ways like an S.

  • color: a CSS color; black by default.
  • width: how thick it is, in pixels; 1 by default.
  • alpha: how opaque it is, from 0.0 to 1.0; 1.0 by default.

Example

import tinyweb as tw
tw.web_init(0)
c = tw.canvas(200, 100)
tw.bezier(c, 10, 50, 60, -20, 140, 120, 190, 50, "crimson", 3)

def bitmap(width: Int, height: Int) -> String

Makes a bitmap: a picture the program builds pixel by pixel. Setting a pixel sends nothing to the page; show_bitmap draws the bitmap on a canvas in one go. It starts black.

Parameters

  • width: its width in pixels.

The bitmap’s identifier, which the other bitmap functions take as b: "bitmap", with a number added where something on the page has that name already.

line_style

def line_style(
    c: String,
    cap: String = "round",
    join: String = "round",
    dash: Float = 0.0,
    gap: Float = 0.0,
    offset: Float = 0.0,
    dash2: Float = 0.0,
    gap2: Float = 0.0,
) -> ()

Sets how lines drawn on the canvas c after it end and turn their corners, and makes them dashed, until pop or the next clear.

Parameters

  • c: the canvas, as canvas answered.

  • dash2, gap2: a second dash and gap, taking turns with the first: a long dash and a dot, say. None by default.
