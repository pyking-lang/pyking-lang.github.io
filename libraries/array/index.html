array

Arrays: copying, filling, comparing, sorting and joining them.

An array is made by the builtins array(...) and array_init(...), read with a[i] and written with a[i] := v, and len(a) and same(a, b) are builtins too (PYKING.md, “Arrays”). This module is the rest. copy, concat and resize make a new array, and copy shallowly: an array of arrays copied still shares its rows. fill, reverse, swap and sort change the array they are given, which everyone holding it sees. Indexing, writing and len take constant time; copying, filling and comparing take time in proportion to the length, and sorting n log n.

bool::equal

def bool::equal(a: Array(Bool), b: Array(Bool)) -> Bool

Whether two arrays of Bools hold the same elements in the same order.

Parameters

  • a: one array.
  • b: the other.

Returns

true when they have the same length and equal elements.

concat

def concat(a: Array(t), b: Array(t)) -> Array(t)

A new array holding the elements of a and then those of b.

Parameters

  • a: the first part.
  • b: the second part.

Returns

A new array of len(a) + len(b) elements.

copy

def copy(a: Array(t)) -> Array(t)

A new array holding the same elements as a, in the same order. Writing to one does not change the other; an element that is itself an array is shared by both.

Parameters

  • a: the array to copy.

Returns

A new array of len(a) elements.

resize

def resize(a: Array(t), n: Int, v: t) -> Array(t)

A new array of n elements: those of a while it has them, and v after that. It is always new, so an old array is never changed.

Parameters

  • a: the array to start from.
  • n: the new length, never negative.
  • v: what fills the elements a does not have.

Returns

A new array of n elements.

Example
