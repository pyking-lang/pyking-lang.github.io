REPL

The REPL reads a piece of Pyking, checks it, runs it, and shows the result. It is the interpreter with a prompt in front of it, so a value means the same as it does in a program run with pyk prog.pyk.

Starting it

:quit (or :q, or Ctrl-D on an empty prompt) leaves.

FlagWhat it does
--use FEATURETurn a feature on from the start, as a use line would: mutation, pointers or objects. Repeat it for several.
-L DIRAnother directory of libraries to import from; see the library search path.
-W...Which warnings to show; see Warnings.
--tinyweb-logPrint what a tinyweb page is sent, and what it answers, on standard error.

The playground has the same REPL in its REPL tab; see below.

Entering code

Each thing you type at the prompt is an entry: one line or several. An entry that is a whole statement on one line runs when you press Enter:

A line that opens a block, such as a def header ending in :, does not run yet. Enter opens the next line, indented one level, and the prompt changes to . . A blank line ends the entry and runs it:

Shift+Return ends the entry at once, whatever it looks like, without the blank line. Not every terminal reports Shift+Return as a key of its own; where it does not, it is an ordinary Return, and the blank line ends the entry.

An if written on one line, such as if c: print(1), waits for a possible else on the next line, so it too ends with a blank line.

Each entry builds on the ones before

An entry sees what earlier entries bound, the way one top-level block of a file sees the blocks above it. Writing a name again in a later entry is ordinary shadowing, so you can redefine a function to fix it:

A function keeps what it saw when it was entered. Redefining a name later does not change a function that already uses it.

Inside one entry, every def can see every other, as inside one block of a file. So two functions that call each other must be typed in the same entry:

use in a session

A file needs a use line before it can use var and :=, and so does a session. A use line typed at the prompt turns the feature on for the rest of the session:

pyk repl --use mutation starts with it on.

Imports

An entry may import a module, as a file does. The module is looked for in the current directory, then on the library search path, which includes the standard library:

A module is loaded once per session, by the first entry that imports it. A program’s standard input is the session’s own, and sys.exit ends the session with its status.

A tinyweb program works too: once an entry has called tinyweb.web_init(), the REPL serves its page and keeps delivering the page’s events while the prompt waits.

Errors

An entry is checked as a whole before any of it runs. If one statement has an error, nothing in the entry runs, and the session is as it was before the entry:

Errors read exactly as they do for a file, with '<repl>' as the file name. A runtime error is reported when it happens, and the session goes on.

An entry that defines a function, and is refused only because it uses a name not defined yet, is not thrown away. The REPL asks:

Escape drops the entry. Any other key puts it back at the prompt, so you can add the missing function to the same entry.

Warnings are shown as for a file, with one difference: a name bound at the top level of an entry is never reported as unused, since a later entry may still use it.

Meta-commands

A line starting with : is a command to the REPL, not Pyking.

CommandWhat it does
:helpList the commands.
:quit, :qLeave (Ctrl-D does too).
:lsList every name the session has bound, with its value and type.
:type EXPRShow the type of an expression, without running it.
:edit NAMEPut the text that defined NAME back at the prompt, to change and enter again.
:ast STMTShow the parsed form of a statement.
:tokens LINEShow the tokens of a line.
:load FILERead a file and enter it as one entry.
:resetForget everything and start a new session.

:load and :quit are the terminal’s only; the playground has the rest.

Keys

KeyWhat it does
EnterRun the entry if it is complete; otherwise start a new, indented line. On a blank line, run the entry.
Shift+ReturnRun the entry now.
TabAt the start of a line, indent. Elsewhere, complete the word before the cursor.
BackspaceIn the indentation, remove one level.
Up, DownMove between the lines of the entry, then through earlier entries.
Left, Right, Home, EndMove the cursor. Ctrl-A and Ctrl-E are Home and End.
Ctrl-KDelete to the end of the line.
Ctrl-LClear the screen.
Escape, Ctrl-CDrop the entry being typed.
Ctrl-DOn an empty prompt, leave.

Completion

Tab completes the word before the cursor. If one name fits, it is completed; if several fit, it completes as far as they agree, and then lists them with their types. What it offers depends on where you are:

  • after m., what module m exports;
  • after import or from, module names: the standard library’s and those the session has imported;
  • after a : at the start of a line, the meta-commands;
  • elsewhere, the names the session has bound, the imported modules, the builtins and the keywords.

History

Up and Down go through the entries typed earlier in the session. They bring back a whole entry, so a function of several lines comes back as one piece, ready to edit. In the terminal, history lasts for the session.

In the playground

The playground’s REPL tab runs the same session in the browser: entries are checked and run the same way, and errors read the same.

  • Enter runs a complete entry or opens a new line, as in the terminal. Shift+Enter always opens a new line. A blank line ends a block. The Keys tab of the settings can change these keys.
  • Tab, Backspace, Escape, Up and Down work as above. The REPL’s history is kept between visits.
  • An entry’s value is shown in green, what it prints in the ordinary colour, and an error in red.
  • The commands are :help, :ls, :type, :edit, :ast, :tokens and :reset.
  • The Environment table below the prompt shows what :ls would list: name, value and type, after every entry.
  • Copy from editor puts the text selected in the editor into the prompt. Stop ends an entry that runs too long, and starts a new session. Reset is :reset. Clear empties the transcript and keeps the session.
  • An entry may import the standard library. io.read_line reads the end of input and sys.args() is empty. tinyweb is refused there: use Run for a program with a page.
