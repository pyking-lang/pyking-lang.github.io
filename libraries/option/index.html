option

Option: a value, or none. Option(a) is Some(value) or None.

Every module that uses Option, Some or None without declaring its own has them as if it began from option import Option (PYKING.md, “Option”); a module declaring its own Option, or its own Some or None, means its own. import option reaches the functions below, named as Rust’s are. fmap, filter, foldl, foldr, any and all take an Option too, as a collection of none or one value, and list(o) makes it a list.

Option

datatype Option(a):
    None
    Some(value: a)

A value, or none: what a pointer that may point nowhere is (PYKING.md, “Pointers”), and what a search that may find nothing answers.

Example

all_some

def all_some(os: [Option(a)]) -> Option([a])

Every value, where every option holds one; otherwise None (Rust’s collect into an Option, Haskell’s sequence).

Parameters

  • os: the options.

Returns

Some of every value in order, or None.

Example

and_then

def and_then(o: Option(a), f: (a) -> Option(b)) -> Option(b)

Goes on with f where o holds a value: the next step of a search that stops at the first None (Haskell’s >>=, OCaml’s bind).

Parameters

  • o: the option so far.
  • f: the next step, given the value.

Returns

What f answers, or None.

Example

expect

def expect(o: Option(a), message: String) -> a

The value o holds; for None the program stops with the runtime error message.

Parameters

  • o: the option, which should hold a value.
  • message: what the runtime error says.

Returns

The value.

Example

flatten

def flatten(oo: Option(Option(a))) -> Option(a)

An option holding an option, as one.

Parameters

  • oo: the option of an option.

Returns

The inner option, or None.

  • o: the option.

or_else

def or_else(o: Option(a), f: () -> Option(a)) -> Option(a)

o where it holds a value, and otherwise what f answers: a second place to look (Rust’s or_else; the default value itself is unwrap_or).

Parameters

  • o: the option.
  • f: called for None only.

Returns

o for a Some, or f().

unwrap_or

def unwrap_or(o: Option(a), default: a) -> a

The value o holds, or default where it holds none (Rust’s unwrap_or, Haskell’s fromMaybe).

Parameters

  • o: the option.
  • default: what to answer for None.

Returns

The value of a Some, or default.

unwrap_or_else

def unwrap_or_else(o: Option(a), f: () -> a) -> a

The value o holds, or what f makes where it holds none: f is called only then.

Parameters

  • o: the option.
  • f: makes the value for None.

Returns

The value of a Some, or f().

values

The values of the options that hold one, in order: the Nones dropped (Haskell’s catMaybes, Rust’s flatten).

Parameters

  • os: the options.

Returns

Every value held, in order.
