prelude

The builtins written in Pyking: fmap, filter, foldl, foldr, any and all over every collection, and the forms of list, list_init, dynarray, dynarray_init, map_init and mutmap_init that make one by calling a function or convert another.

Nothing imports this module: a module calling one of those names, and binding none of them itself, has every one of the definitions below under its :: name, as if it began from prelude import list::fmap, ... (PYKING.md, “fmap and the folds”). Each name is an overload set, and a call is resolved by the kind of collection it is given — which has to be known where the call is, written or worked out. A module’s own filter or list means itself.

Each function answers a new collection of the kind it was given, and making an array, a DynArray or a MutMap needs use mutation in the calling module. A Map’s and a MutMap’s elements here are its values. The functions call f once per element, in order: foldr from the last, and any and all stopping at the first answer that decides.
