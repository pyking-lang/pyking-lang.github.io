tinyweb.sound

Sound beyond play: voices that can be stopped and faded, tones made without a sample, a beat scheduled ahead of time, channels with effects, and listening to what plays.

Most sounds are fired and forgotten with tw.play. A sound that has to be controlled while it plays — music that loops until the level ends, a note held while a key is down — is a voice: start begins one and answers its identifier, which stop and fade take.

The beat is kept by the page, a little ahead of time, so it stays exact however far away the program runs: on_beat calls a function for each step with the step’s exact time, and a sound played at that time lands on it.

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
kick = tw.load_sample("kick1.wav")
hat = tw.load_sample("hihat1.wav")
def step(n: Int, time: Float):
    if n - n / 4 * 4 == 0:
        tw.play(kick, at = time)
    tw.play(hat, at = time, volume = 0.4)
sound.tempo(110.0)
sound.on_beat(step, steps = 4)

Voices

sound.Voice

struct sound.Voice(volume = 1.0, rate = 1.0, pan = 0.0, channel = 0, looping = false, reverse = false)

How a sound is played, defined once and given to tw.play and start as voice = .... A sound’s own argument left at its default takes the voice’s value.

Parameters

  • volume: how loud, as a multiple of the sample’s own volume.
  • rate: how fast: 2.0 is twice as fast and an octave higher.
  • pan: where it is heard, from -1.0 (left) to 1.0 (right).
  • channel: the channel it goes through, from 0; 0 by default.
  • looping: whether start plays it again and again until stopped.
  • reverse: whether it plays backwards.

Example

sound.start

def sound.start(
    sample: String,
    at: Float = 0.0,
    volume: Float = 1.0,
    rate: Float = 1.0,
    pan: Float = 0.0,
    looping: Bool = false,
    voice: sound.Voice = sound.Voice(),
) -> String

Starts playing a sample as a voice, which stop and fade can change while it plays: music that loops, an engine that hums while a key is held.

Parameters

  • sample: the sample, as tw.load_sample answered.
  • at: when, on the page’s clock; now by default.
  • volume: how loud.
  • rate: how fast: 2.0 is twice as fast and an octave higher.
  • pan: where it is heard, from -1.0 (left) to 1.0 (right).
  • looping: whether it plays again and again until stopped.
  • voice: a Voice for what is not given here.

Returns

The voice’s identifier: "voice", with a number added where something on the page has that name already.

sound.stop

def sound.stop(voice: String, at: Float = 0.0) -> ()

Stops a voice, now or at a time on the page’s clock.

Parameters

  • voice: the voice, as start answered.
  • at: when; now by default.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
music = sound.start(tw.load_sample("piano_c1.wav"), looping = true)
sound.stop(music, at = tw.time() + 2.0)

sound.fade

def sound.fade(voice: String, volume: Float, over: Float = 1.0) -> ()

Changes a voice’s volume smoothly, from what it is now to volume over over seconds: a fade to 0.0 and then a stop is a fade-out.

Parameters

  • voice: the voice, as start answered.
  • volume: the volume to reach.
  • over: how long it takes, in seconds; 1.0 by default.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
music = sound.start(tw.load_sample("piano_c1.wav"), looping = true)
def game_over():
    sound.fade(music, 0.0, over = 2.0)
    sound.stop(music, at = tw.time() + 2.0)
tw.button("Game over", on_click = game_over)

Tones and notes

sound.tone

def sound.tone(
    frequency: Float,
    at: Float = 0.0,
    duration: Float = 0.5,
    wave: String = "sine",
    volume: Float = 0.5,
    pan: Float = 0.0,
    channel: Int = 0,
) -> ()

Plays a tone made without a sample: a wave at frequency, with a short attack and release so it does not click.

Parameters

  • frequency: how high, in hertz: 440.0 is the A above middle C.
  • at: when, on the page’s clock; now by default.
  • duration: how long, in seconds.
  • wave: its shape: "sine", "square", "triangle" or "sawtooth".
  • volume: how loud; 0.5 by default.
  • pan: where it is heard, from -1.0 (left) to 1.0 (right).
  • channel: the channel it goes through.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
def beep():
    sound.tone(sound.note("A4"), duration = 0.2, wave = "square", volume = 0.2)
tw.button("Beep", on_click = beep)

sound.note

def sound.note(name: String) -> Float

The frequency of a note named the usual way: a letter from A to G, a # or b for sharp or flat, and the octave, where "A4" is 440 Hz and "C4" is middle C.

Parameters

  • name: the note, such as "C4", "F#3" or "Bb5".

Returns

Its frequency in hertz; 0.0 for a name that is not a note.

sound.on_beat

def sound.on_beat(f: (Int, Float) -> (), steps: Int = 4) -> String

Calls f a little ahead of each step of the beat, steps to a beat, with the step’s number, counting from 0 when the beat started, and its exact time on the page’s clock: a step sequencer is the steps to play and an on_beat that plays them at that time.

Parameters

  • f: what is called with each step and its time.
  • steps: how many steps a beat is cut into: 4 is sixteenth notes.

Returns

The beat’s identifier, which tw.cancel stops.

Example

sound.beat

def sound.beat() -> Float

Where the beat is, as of the last event, as a number of beats with a fraction: what a frame draws a pulse from.

Returns

The beat; 0.0 until a beat has started.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
c = tw.canvas(100, 100)
def frame(t: Float):
    phase = sound.beat() - float(int(sound.beat()))
    tw.clear(c)
    tw.circle(c, 50, 50, 40 - int(phase * 30.0))
tw.on_frame(frame)

Channels and effects

sound.channel_style

def sound.channel_style(
    channel: Int,
    volume: Float = 1.0,
    pan: Float = 0.0,
    echo: Float = 0.0,
    echo_time: Float = 0.3,
    feedback: Float = 0.35,
    reverb: Float = 0.0,
    low_pass: Float = 0.0,
) -> ()

Sets how a channel sounds: every sound played through it (channel in a Voice, or tone’s) goes through its volume, pan, filter, echo and reverb. Channel 0 is where every sound goes unless told otherwise.

Parameters

  • channel: the channel, from 0.
  • volume: how loud.
  • pan: where it is heard, from -1.0 (left) to 1.0 (right).
  • echo: how loud its echo is, 0.0 (none) to 1.0.
  • echo_time: how long after the sound the echo comes, in seconds.
  • feedback: how much of each echo echoes again, 0.0 to 0.95.
  • reverb: how much of a room it sounds in, 0.0 to 1.0.
  • low_pass: a filter’s frequency in hertz: above it the sound dulls; 0.0 for no filter.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
sound.channel_style(1, echo = 0.4, echo_time = 0.25, reverb = 0.3)
snare = tw.load_sample("snare1.wav")
def hit():
    tw.play(snare, voice = sound.Voice(channel = 1))
tw.button("Snare", on_click = hit)

Listening

sound.listen

def sound.listen(bins: Int = 32, smoothing: Float = 0.8) -> ()

Starts listening to what plays: from then on every frame the page reports how loud it is (level), how loud each of bins frequency bands is (band) and the wave itself (wave).

Parameters

  • bins: how many bands and wave points; 32 by default, up to 1024.
  • smoothing: how much each frame’s bands are kept from the last one’s, 0.0 to 0.99.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
sound.listen(bins = 64)

Rendering

sound.render_wav

def sound.render_wav(
    seconds: Float,
    f: () -> (),
    name: String = "tinyweb.wav",
    on_rendered: (Float, Float) -> () = sound.ignore_rendered,
) -> ()

Renders sound into a WAV file instead of playing it: everything f plays or starts, with times from 0.0, through the channels as they are set, much faster than it would play. The file is offered to the reader to save, and on_rendered is called with how long rendering took and how loud its loudest moment is.

Parameters

  • seconds: how long the file is.
  • f: what plays the sound, with at from 0.0.
  • name: the file’s name.
  • on_rendered: what is called with the seconds rendering took and the peak level, 0.0 to 1.0.

Example

import tinyweb as tw
import tinyweb.sound as sound
tw.web_init(0)
kick = tw.load_sample("kick1.wav")
def beat():
    for k in range(4):
        tw.play(kick, at = float(k) * 0.5)
def done(took: Float, peak: Float):
    print("rendered in", took)
sound.render_wav(2.0, beat, name = "beat.wav", on_rendered = done)
