result

Result: a value, or the error that stopped it. Result(t, e) is Ok(value) or Error(error), as Rust’s is (with Error for Rust’s Err).

Every module that uses Result, Ok or Error without declaring its own has them as if it began from result import Result (PYKING.md, “Result”); a module declaring its own Result, or its own Ok or Error, means its own. import result reaches the functions below. fmap, foldl, foldr, any and all take a Result too, acting on its Ok value.

Result

datatype Result(t, e):
    Ok(value: t)
    Error(error: e)

A value, or the error that stopped it: what a function answers when it may fail and should say why.

Parameters

  • value: what an Ok holds.
  • error: what an Error holds — a String saying what went wrong, or a datatype of the ways it can.

Example

all_ok

def all_ok(rs: [Result(t, e)]) -> Result([t], e)

Every value, where every result is an Ok; otherwise the first error (Rust’s collect into a Result, Haskell’s sequence).

Parameters

  • rs: the results.

Returns

Ok of every value in order, or the first Error.

Example

and_then

def and_then(r: Result(t, e), f: (t) -> Result(u, e)) -> Result(u, e)

Goes on with f where r is an Ok: the next step of a computation that stops at the first error (Haskell’s >>=, OCaml’s bind).

Parameters

  • r: the result so far.
  • f: the next step, given the Ok value.

Returns

What f answers, or the same Error.

map_error

def map_error(f: (e) -> g, r: Result(t, e)) -> Result(t, g)

r with f applied to its error: what fmap is to the Ok value (Rust’s map_err). The function comes first, as fmap’s does.

Parameters

  • f: applied to the error.
  • r: the result.

Returns

The same Ok, or Error(f(error)).

ok_or

def ok_or(o: Option(t), problem: e) -> Result(t, e)

An Option as a Result: None becomes Error(problem) (Rust’s Option::ok_or; it lives here so that lib/option needs no Result).

Parameters

  • o: the option.
  • problem: the error to give for None.

Returns

Ok(value) for a Some, Error(problem) for None.
