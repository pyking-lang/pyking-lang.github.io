Setting up Pyking

Pyking is one program, pyk, together with its standard library. This page says how to install it, what you can do with it then, and how to set up your editor.

Installing Pyking

One command installs it on each platform. The Install page has the details: other options, upgrading and removing it.

What each target needs to run

The interpreter, the REPL, the playground and the notebook need nothing but pyk. Running a compiled program needs its target’s own tools. Compiling alone needs none of them.

targetto run the result, you need
pythonpython3, 3.12 or later
nodenode, 22 or later
web, iweba browser; --run serves the page with pyk serve
ca C compiler, cc
c-gca C compiler with C23, and the bdwgc collector: brew install bdw-gc on macOS, apt install libgc-dev on Debian and Ubuntu, dnf install gc-devel on Fedora
javaa JDK, 21 or later (java8 and java17 are older targets)
ocamlocamlopt, 4.14 or later

A version in the table is that family’s default target, which names the oldest version its output runs on. See Compiler targets for the others.

Interpreting a program that has an external module of its own needs the OCaml compiler that pyk was built with. The standard library works without it.

What the language server is

The Language Server Protocol (LSP) is a standard way for an editor to talk to a program that knows a language. pyk lsp is that program for Pyking. Every editor starts the same pyk lsp, so every editor gets the same features:

  • Diagnostics: the first error in a file, as you type, and its warnings.
  • Hover: the type of what is under the cursor, and a name’s ## comment.
  • Go to definition, references and rename.
  • Completion, and signature help while a call is typed.
  • Inlay hints: the types the checker inferred, shown where none is written.
  • Quick fixes, such as the use mutation line a var needs.
  • Outline, folding and semantic highlighting.

The server is part of pyk, so nothing else needs installing: an editor only needs to know how to start it. The debugger, pyk dap, works the same way, over the Debug Adapter Protocol (DAP); see Debugging.
