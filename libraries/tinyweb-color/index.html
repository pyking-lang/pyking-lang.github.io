tinyweb.color

Colours, and the paints a shape can be filled with.

A colour is a Color: how much red, green and blue, each from 0 to 255, and how opaque it is, from 0.0 (not at all) to 1.0. Make one with rgb, rgba, hsl or hex, take one of the named ones (black, white, red, …), or write Color(255, 136, 0). none is fully transparent: a shape with stroke = color.none has no outline.

A Paint is what fills a shape: a plain colour, or a linear, radial or conic gradient between two colours, with more stops added by stop.

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 100)
tw.clear(c, color.navy)
tw.circle(c, 50, 50, 30, color.rgb(255, 136, 0), stroke = color.white)
sky = color.Linear(0.0, 0.0, 0.0, 100.0, color.blue, color.white)
tw.rect(c, 110, 10, 80, 80, paint = sky)

color.hsl

def color.hsl(h: Float, s: Float, l: Float) -> color.Color

A colour from its hue, saturation and lightness: the easy way to walk round the colour wheel.

Parameters

  • h: the hue, an angle on the colour wheel in degrees: 0 is red, 120 green and 240 blue.
  • s: the saturation, from 0 (grey) to 100 (the purest colour).
  • l: the lightness, from 0 (black) to 100 (white); 50 is the colour itself.

Returns

The colour, fully opaque.

Paints and gradients

color.Paint

datatype color.Paint:
    Plain(color.Color)
    Linear(x1: Float, y1: Float, x2: Float, y2: Float, start: color.Color, end: color.Color, stops = "")
    Radial(x1: Float, y1: Float, r1: Float, x2: Float, y2: Float, r2: Float, start: color.Color, end: color.Color, stops = "")
    Conic(x: Float, y: Float, angle: Float, start: color.Color, end: color.Color, stops = "")

What fills a shape: a plain colour, or a gradient between two colours across a line (Linear), out from a circle (Radial) or round a point (Conic). Positions are in the canvas’s pixels, and an angle is in radians. stop adds a colour on the way; stops is how those are kept, and is left out when one is written.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 100)
glow = color.Radial(100.0, 50.0, 0.0, 100.0, 50.0, 50.0, color.yellow, color.none)
tw.circle(c, 100, 50, 50, paint = glow)

color.stop

def color.stop(
    paint: color.Paint,
    at: Float,
    c: color.Color,
) -> color.Paint

A gradient with one more colour on the way: at 0.0 is where it starts and 1.0 where it ends. A plain colour is left as it is.

Parameters

  • paint: the gradient.
  • at: where the colour is, from 0.0 to 1.0.
  • c: the colour.

Returns

The gradient.

Example

import tinyweb as tw
import tinyweb.color as color
tw.web_init(0)
c = tw.canvas(200, 40)
rainbow = color.stop(color.Linear(0.0, 0.0, 200.0, 0.0, color.red, color.blue), 0.5, color.green)
tw.rect(c, 0, 0, 200, 40, paint = rainbow)
