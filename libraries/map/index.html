map

Maps: a new Map with an entry put in, taken out or changed, and the rest of what a Map is asked.

A Map is made by map(...) or map_init(...), read with m[k], get, has, keys, values, items and len, which are builtins, as fmap, filter and the folds on its values are (PYKING.md, “Maps”). A Map is never changed: each function here that changes one answers a new Map and leaves the one it was given as it was. A new key goes at the end, a key already there keeps its place, and one taken out and put back goes to the end, as in a MutMap.

Each change copies the Map, so it takes time in proportion to its size: a Map built one entry at a time in a loop is better built as a list of pairs, or as a MutMap, and then made one with map(...).

Parameters

alter

def alter(
    f: (Option(v)) -> Option(v),
    m: Map(k, v),
    key: k,
) -> Map(k, v)

m with the entry for key as f says: f is given its value or None, and answers the new value or None to take the entry out (Haskell’s alter).

Parameters

  • f: the old value, if any, to the new, if any.
  • m: the Map.
  • key: the key.

Returns

A new Map.
