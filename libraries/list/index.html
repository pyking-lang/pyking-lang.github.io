list

Lists: taking parts, searching, combining, counting and sorting them.

A list is made by a literal, a comprehension, list(...) or list_init(...), and len, fmap, filter, foldl, foldr, any and all are builtins (PYKING.md, “Lists”, “fmap and the folds”). This module is the rest, named as Haskell names them where Haskell, OCaml and Rust differ. A list is never changed: every function answers a new one. Where a function is given a function, it comes first, and the list comes last.

A function that compares elements — contains, unique, sort, maximum — is written once for each of Int, Float, String, Char and Bool where it can be, and once more as ..._by, taking the comparison as a function, for every other element type. Floats sort with every NaN last, and Strings by code point, the same on every target.
