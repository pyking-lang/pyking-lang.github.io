Libraries

The standard library comes with every installation of Pyking. A program uses a module by importing it, and needs no flag to find it:

import io

io.write("Hello, ")
io.write_line("libraries")
Module
fsReading and writing files.
ioStandard input and standard output.
sysThe process this program is running as: its arguments, its name, and its environment.
timeDates and times: reading the clock, and rendering an instant.
tinywebGraphics, widgets and sound on a web page, kept in time with each other.

These pages are generated from the libraries’ own source, in lib/.
