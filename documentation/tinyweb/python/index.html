tinyweb for Python

tinyweb’s Python implementation is a library of its own: a Python program can use it to draw on a web page, add buttons, labels and sliders to it, play sounds and answer the reader, with no Pyking anywhere. It is the file Pyking copies beside a program compiled for python14, renamed tinyweb.py.

Download tinyweb-python.zip: tinyweb.py, the example below, and the samples in tinyweb_assets/.

Running a program

The program serves its own page: web_init starts the server and prints its address, and once the program’s own code has finished it goes on serving the page and calling the functions it handed over until it is stopped (Ctrl-C). Open the address in a browser.

The page asks for a sample beside where the program runs first, then in tinyweb_assets/ there.

An example

Functions

Every function but web_init needs web_init to have been called first, or PYKING_TINYWEB_LOG to be set (below); otherwise it says so and the program ends with status 1.

web_init

Serves the program’s page on port and prints its address, tinyweb: http://127.0.0.1:N/; port 0 picks any free port. Call it before anything else. With PYKING_TINYWEB_LOG set it does nothing.

canvas

A new canvas, width by height pixels, placed below what the page already shows. Answers the number that names it.

fill_canvas

Fills the whole canvas c with color, a CSS color such as "#ff0000" or "red".

draw_circle

A filled circle on the canvas c, centred at (x, y).

draw_rect

A filled rectangle on the canvas c, with its top left corner at (x, y).

draw_line

A straight line on the canvas c, from (x1, y1) to (x2, y2), width pixels wide.

draw_text

words written on the canvas c, with the top left corner of the text at (x, y), size pixels high.

make_button

A button showing title, placed below what the page already shows, which calls on_click each time it is pressed. Answers the number that names it.

label

A line of text, placed below what the page already shows. Answers the number that names it to set_label.

set_label

Replaces the text of the label id with text.

make_slider

A slider from low to high, starting at value, placed below what the page already shows, which calls on_change with each new value it is moved to. Answers the number that names it.

apply_style

Changes the page’s look. With kind “theme”, value names a theme: “light” (the default), “dark”, “plain”, “paper” or “retro”. With kind “page”, “button”, “label”, “slider” or “canvas”, property of every element of that kind becomes value; with kind “element”, only the element id’s. property is one of background, color, border, radius, font, size, padding, gap, accent and width, and value is CSS, such as “#336699” or “12px”. id is 0 except for an element.

load_sample

Starts loading the sound file name and answers a number naming it to play_sample. The name is looked up beside where the program runs first, and then among the samples tinyweb ships in tinyweb_assets/: kick1.wav, snare1.wav, hihat1.wav and piano_c1.wav.

play_sample

Plays the sample sample: at the time at on the page’s clock, or now if that has passed; volume times as loud, and rate times as fast, which raises its pitch as much.

time

The page’s clock, in seconds, as the page last reported it: inside an on_frame callback, the time the frame is for. It is the audio clock once sound has started, so a time read here is a time play_sample can be given.

on_frame

Calls draw before each frame the page shows, with the time the frame is for.

on_mouse

Calls click with the position, in pixels from the top left corner, of every click on the canvas c.

on_key

Calls pressed with the name of every key pressed while the page has the focus: a letter or digit as itself, and otherwise the browser’s name for it, such as “ArrowLeft”, “Enter” or ” ”.

Without a page

Two environment variables, each a file path, run a program with no page at all, which is how it is tested: with PYKING_TINYWEB_LOG set, every command the program would send its page is appended to that file as one line, and once the program’s own code has finished the events PYKING_TINYWEB_EVENTS lists — click ID, slide ID VALUE, frame T, mouse ID X Y, key NAME, one per line — are delivered as if a reader had caused them.
