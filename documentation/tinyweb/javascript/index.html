tinyweb for JavaScript

tinyweb’s JavaScript implementation is a library of its own: a JavaScript program can use it to draw on a web page, add buttons, labels and sliders to it, play sounds and answer the reader, with no Pyking anywhere. It is the file Pyking copies beside a program compiled for node24, renamed tinyweb.js.

Download tinyweb-javascript.zip: tinyweb.js, the example below, and the samples in tinyweb_assets/.

Running a program

The program serves its own page: web_init starts the server and prints its address, and once the program’s own code has finished it goes on serving the page and calling the functions it handed over until it is stopped (Ctrl-C). Open the address in a browser.

The page asks for a sample beside where the program runs first, then in tinyweb_assets/ there.

An example

Functions

Every function but web_init needs web_init to have been called first, or PYKING_TINYWEB_LOG to be set (below); otherwise it says so and the program ends with status 1.

web_init

Serves the program’s page on port and prints its address, tinyweb: http://127.0.0.1:N/; port 0 picks any free port. Call it before anything else. With PYKING_TINYWEB_LOG set it does nothing.

canvas

A new canvas, width by height pixels, placed below what the page already shows. Answers the string that names it: “canvas”, with a number added where something on the page has that name already.

fill_canvas

Fills the whole canvas c with color, a CSS color such as "#ff0000" or "red".

draw_shape

One shape on the canvas c. kind is “rect”, “circle”, “ellipse”, “arc”, “line”, “lines”, “curve”, “bezier”, “polygon”, “path” or “erase”, and numbers its numbers as words: x y width height radius for a rect, x y r for a circle, x y rx ry for an ellipse, x y r start end (degrees) for an arc, x1 y1 x2 y2 for a line, x1 y1 x2 y2 for each of many lines, x1 y1 cx cy x2 y2 for a curve, x1 y1 ax ay bx by x2 y2 for a bezier, x y x y … for a polygon or a path, and x y width height for the rectangle erase makes transparent. It is filled with color and outlined with outline, width pixels thick, each unless it is "", at alpha from 0.0 to 1.0. A color may be a gradient: “linear-gradient(x1 y1 x2 y2); 0.0 red; 1.0 blue”, “radial-gradient(x1 y1 r1 x2 y2 r2); …” or “conic-gradient(x y angle); …”, each stop its place from 0.0 to 1.0 and a CSS color.

draw_pairs

Many shapes’ numbers in one go, as a list rather than as words: kind “polygon” or “path” through the points (x, y) in items, drawn as draw_shape draws one. Not in C, which cannot be given a list.

draw_triples

Many circles in one go: kind “circles”, each (x, y, radius) in items filled and outlined on its own, as draw_shape draws one. Not in C, which cannot be given a list.

draw_quads

Many separate lines in one go: kind “lines”, each (x1, y1, x2, y2) in items, stroked together as one. Not in C, which cannot be given a list.

draw_text

words written on the canvas c at (x, y): its left end there, or with align “center” or “right” its middle or right end, and its top there, or with baseline “middle”, “alphabetic” or “bottom” that part of it. size pixels high, in font ("" for the page’s own), bold where bold is true, filled with color and outlined with outline outline_width pixels thick, each unless it is "", at alpha.

set_state

Changes what the next drawing on the canvas c is drawn with. kind “translate”, “rotate” or “scale” take their numbers (x y, degrees, sx sy) in numbers; “push” and “pop” save and restore the state; “reset” takes every transformation off; “shadow” takes a color in value ("" for none) and blur dx dy in numbers; “blend” takes “normal” or “add” in value; “line_style” takes how lines end and turn in value (“round round”, “butt miter”, …) and the dash offset followed by the dash and gap lengths in numbers; “clip” keeps what is drawn after it inside a shape, its kind in value and its numbers as draw_shape takes them. fill_canvas starts the canvas afresh.

measure

Asks the page how wide words is written size pixels high in font, bold where bold is true, and calls answer with the width in pixels once the page has said.

watch_pointer

Calls f with where the pointer is on the canvas c, in pixels from its top left corner, each time it goes down there (kind “press”), comes up (“release”), moves over it (“move”) or moves with the button held (“drag”).

pointer

Where the pointer was last seen on the canvas c: which “x” or “y” for its position, “down” for 1 while its button is held and 0 otherwise. The canvas reports the pointer once watch_pointer has been called for it.

draw_image

Draws a loaded picture on the canvas c, its top left corner at (x, y), stretched to width by height, at alpha. One still loading is not drawn.

bitmap

A picture width by height pixels the program builds, all black, kept by the program: setting a pixel sends nothing. Answers the string that names it: “bitmap”, with a number added where something on the page has that name already.

set_pixel

Sets the pixel (x, y) of the bitmap b to color, red times 65536 plus green times 256 plus blue. A pixel outside it is left alone.

get_pixel

The color of the pixel (x, y) of the bitmap b, as set_pixel takes one; 0 outside it.

fill_bitmap

Sets every pixel of the bitmap b to color.

draw_bitmap

Draws the bitmap b on the canvas c, its top left corner at (x, y), each pixel scale pixels across: sharp squares above 1.0. What changed since it was last drawn is sent to the page.

load_image

Starts loading the picture name, looked for as a sample is, and answers the string that names it to draw_image.

make_button

A button showing title, placed below what the page already shows, which calls on_click each time it is pressed. Answers the string that names it: title, with a number added where something on the page has that name already.

label

A line of text, placed below what the page already shows. Answers the string that names it to set_label: text, with a number added where something on the page has that name already.

row

A box placed below what the page already shows, whose elements go side by side, wrapping where the page is too narrow. Answers the string that names it to inside: “row”, with a number added where something on the page has that name already.

column

A box whose elements go one below another, as the page’s own do: inside a row, it stands beside the row’s other elements. Answers the string that names it to inside.

inside

Makes every element made after it go into the row or column id, until outside or another inside.

outside

Makes every element made after it go on the page again, below what is there.

set_label

Replaces the text of the label id, or the title of the button id, with text.

make_slider

A slider from low to high, starting at value, placed below what the page already shows, which calls on_change with each new value it is moved to. Answers the string that names it: “slider”, with a number added where something on the page has that name already.

make_checkbox

A checkbox showing title, ticked where checked is true, which calls on_change with whether it is ticked each time the reader changes it. Answers the string that names it.

make_radio

A radio button showing title in the group group: choosing one clears the others. The first of a group starts chosen unless one says chosen. Calls on_pick with title when the reader chooses it. Answers the string that names it.

make_choice

A dropdown of options, one per line, the one at position chosen chosen, which calls on_change with the position the reader chooses. Answers the string that names it.

make_text_input

A line to type text into, showing placeholder while empty, which calls on_enter with the text when Enter is pressed in it. Answers the string that names it.

make_number_input

A field for a whole number from low to high, starting at value, which calls on_change with each new number. Answers the string that names it.

set_checked

Ticks or clears the checkbox id, or chooses the radio button id.

set_value

Moves the slider or number field id to value, or picks the dropdown choice at that position.

apply_style

Changes the page’s look. With kind “theme”, value names a theme: “light” (the default), “dark”, “plain”, “paper” or “retro”. With kind “page”, “button”, “label”, “slider” or “canvas”, property of every element of that kind becomes value; with kind “element”, only the element id’s. property is one of background, color, border, radius, font, size, padding, gap, accent and width, and value is CSS, such as “#336699” or “12px”. id is "" except for an element.

load_sample

Starts loading the sound file name and answers a string naming it to play_sample: name, with a number added where something on the page has that name already. The name is looked up beside where the program runs first, and then among the samples tinyweb ships in tinyweb_assets/: kick1.wav, snare1.wav, hihat1.wav and piano_c1.wav.

play_sample

Plays the sample sample: at the time at on the page’s clock, or now if that has passed; volume times as loud, and rate times as fast, which raises its pitch as much.

splash

Shows the splash screen: the page dimmed, and a message asking the reader to click, since a browser plays no sound before the reader has clicked or pressed a key. The page waits there — what the program draws next, its frames and its clock — until the reader does. It is shown at most once, and not at all where the reader has already clicked. The first play_sample before a click shows it too; a program that plays sound only from callbacks calls it at the end of its main code.

set_splash

Sets what the splash screen says, “Click to Start” until it is set. An empty message turns the splash screen off.

time

The page’s clock, in seconds, as the page last reported it: inside an on_frame callback, the time the frame is for. It is the audio clock once sound has started, so a time read here is a time play_sample can be given.

on_frame

Calls draw before each frame the page shows, with the time the frame is for.

on_mouse

Calls click with the position, in pixels from the top left corner, of every click on the canvas c.

on_key

Calls pressed with the name of every key pressed while the page has the focus: a letter or digit as itself, and otherwise the browser’s name for it, such as “ArrowLeft”, “Enter” or ” ”.

on_key_up

Calls released with the name of each key let go while the page has the focus. Leaving the page lets go of every key held.

key_down

Whether the key named key is held down now.

Without a page

Two environment variables, each a file path, run a program with no page at all, which is how it is tested: with PYKING_TINYWEB_LOG set, every command the program would send its page is appended to that file as one line, and once the program’s own code has finished the events PYKING_TINYWEB_EVENTS lists — click ID, slide ID VALUE, check ID true, pick ID, choose ID INDEX, enter ID TEXT, frame T, mouse ID X Y, press ID X Y, move ID X Y, release ID X Y, key NAME, key_up NAME and measured ID WIDTH, one per line, each ID and TEXT a quoted string — are delivered as if a reader had caused them.
